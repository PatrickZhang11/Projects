SOC-2026-0812-002
Password Spray Detection Lab
Detection Validated

Built a live Active Directory domain (40 user accounts, real lockout policy), forwarded Security logs to Splunk via Windows Event Forwarding, then ran a password spray attack against it two different ways — NTLM/SMB and Kerberos pre-authentication — to test whether a detection built for one telemetry source would silently miss the other. It did, which is the actual finding: three layered detections were needed to close the gap, keyed on breadth-of-accounts-targeted rather than any single account's failure count.
